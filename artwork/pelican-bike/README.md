# Пеликан на велосипеде

Векторная иллюстрация: пеликан едет на велосипеде и держит руль крылом.

| Файл | Описание |
|---|---|
| `pelican-bike.svg` | Исходный вектор (viewBox `0 0 1200 900`), без внешних зависимостей |
| `pelican-bike.png` | Растр 1200×900 |
| `pelican-bike@2x.png` | Растр 2400×1800 (для печати и презентаций) |

## Состав иллюстрации

- **Пеликан** — длинный оранжевый клюв с розовым горловым мешком, жёлтая «когтистая» окантовка клюва,
  белая голова с жёлтым пятном вокруг глаза, кремовое тело с тенью на брюшке, хвост из трёх перьев,
  крыло с тёмными маховыми перьями, обхватывающее руль, оранжевые лапы с перепонками на педалях.
- **Велосипед** — бирюзовая рама, спицованные колёса, цепь, звёздочка с шатунами, вилка, руль, седло.
- **Фон** — градиентное небо, солнце с ореолом, облака, дальние птицы, холмы, трава, асфальт с разметкой и тень.

## Перерендер PNG из SVG

Требуется Node.js 18+:

```bash
cd artwork/pelican-bike
npm install
npm run render
```

Или разово:

```bash
node render.mjs pelican-bike.svg out.png 1200   # ширина в px, высота считается по пропорции
```

Рендер выполняет [`@resvg/resvg-js`](https://github.com/yisibl/resvg-js) — не требует системного
`librsvg`/`cairo`, поэтому результат одинаков на любой машине.
