# RFAB Online — clean-core rebuild

> **Разработка, `5.0.0-dev.1`. Это НЕ готовая сборка для совместной игры.**
> Цель — один полный кандидат со всеми согласованными RFAB-механиками и один итоговый плейтест.
> Внутренние коммиты и CI-артефакты не являются промежуточными релизами.

## База

- Skyrim Together Reborn / TiltedEvolution: `13ff0b5a934bf3016c8c898d9a019aa04e5c1fb0`.
- Порт Skyrim SE 1.5.97 / SKSE 2.0.20, compatibility overlay, установщик и сборщик отчёта:
  `ovococjsjs-gif/RFABTogether@64e432ee7e397e79c3ff63a684667eced8bad331`.
- Происхождение импорта: [`docs/RFAB_CLEAN_BASELINE.json`](docs/RFAB_CLEAN_BASELINE.json).
- Работа ведётся на текущей ветке этого репозитория; старые теги и выпущенные сборки не переписываются.

## Что будет в едином кандидате

Ранение без смерти, неограниченное ожидание помощи, подъём за 5 секунд; основной reset encounter
с безопасными точками в интерьерах и открытом мире, опциональная согласованная загрузка checkpoint;
одинаковая базовая награда XP с личными множителями RFAB; ×2 HP врагов на двоих; арбитрация лута,
QuickLoot/AutoLoot и общее постоянное защищённое хранилище кампании.

**Это перечень цели, не заявление о работающих возможностях.** Реальные состояния этапов:
[`docs/RFAB_RELEASE_STATUS.json`](docs/RFAB_RELEASE_STATUS.json), журнал:
[`docs/RFAB_REBUILD_WORKLOG.md`](docs/RFAB_REBUILD_WORKLOG.md).
Подробный исходный аудит и ограничения: [`план`](docs/RFAB_RESTART_PLAN_2026_11_17.md).
Старые документы и changelog описывают исторические версии, а не текущую ветку.

Установленная версия RFAB новее публичной. Её не ищем и не подменяем устаревшими данными.
Интеграция строится по проверяемым возможностям и привязкам; неизвестный путь RFAB/Bizarre не должен
превращаться в угаданные награды или запись по неподтверждённым адресам. Полная совместимость
с любым будущим обновлением без проверки не гарантируется.

## Проверки без второго игрока

```sh
Tools/rfab/run-core-tests.sh
Tools/rfab/run-core-tests.sh --asan
Tools/rfab/linux-server/run-server-tests.sh --plain
Tools/rfab/linux-server/run-server-tests.sh --asan
Tools/rfab/run-static-checks.sh
```

Linux-стенд исполняет production-сервисы и настоящий разбор пакетов; сокетный транспорт заменён
регистратором исходящих пакетов. Он не запускает Skyrim и не доказывает работу AI/анимаций/модов.
Windows-сборка клиента, сервера, UI и установщика выполняется существующим CI. Публикация запрещена
манифестом readiness до готовности всего кандидата; внутренние диагностические архивы допустимы.

## Установка и диагностика

Рабочий установщик и сборщик отчётов сохранены. Пока readiness=false, не устанавливайте
промежуточные артефакты поверх единственного игрового профиля/сейва. Для будущего кандидата
будут отдельные инструкции, точный build ID и путь отката.

`COLLECT_RFAB_REPORT.bat` / `Tools/rfab/Collect-RfabReport.ps1` собирают локальный архив отчёта;
ничего автоматически не отправляют. Отчёты обоих клиентов и сервера нужны после итогового плейтеста.
