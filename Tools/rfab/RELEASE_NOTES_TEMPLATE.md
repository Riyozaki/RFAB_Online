# RFAB Online {{VERSION_TAG}} — Актуальный автономный релиз (Skyrim SE `1.5.97.0.8`)

Полностью собранный на чистой облачной машине `Windows x64` автономный установщик **RFAB Online** (клиент для **Mod Organizer 2** + русский CEF-оверлей + выделенный кооп-сервер).
Никаких консольных команд, `git`, `xmake` или ручного удаления/копирования папок **не требуется**!

---

## 📦 Состав релиза

| Файл | Назначение |
|---|---|
| **`RFAB_Online_{{VERSION_TAG}}_Full_Installer.zip`** | **Основной архив (рекомендуется как для первой установки, так и для чистого обновления)**: автоматически удаляет старую версию и ставит новую с нуля (`INSTALL_RFAB_ONLINE.bat`) |

## 🛠 Установка и чистое обновление с прошлой версии (одинаково Хосту и Друзьям)

1. Скачайте **`RFAB_Online_{{VERSION_TAG}}_Full_Installer.zip`** и распакуйте архив в любую временную папку.
2. Закройте игру и **Mod Organizer 2**, затем запустите **`INSTALL_RFAB_ONLINE.bat`**:
   - Откроется окно выбора папки сборки RFAB (автоматически найдёт `ModOrganizer.exe` и проверит `SkyrimSE.exe 1.5.97` по `ModOrganizer.ini`).
   - **Автоматическая чистая замена старой версии:** установщик сам остановит запущенный сервер, **полностью удалит старые файлы прошлых версий** из `MO2\mods\RFAB_Online`, `RFAB_Online_Server` и устаревшие хвосты в `MO2\overwrite` (сохранив и обновив ваш `STServer.ini`), после чего установит свежую сборку без наслоения файлов.
   - Включит `+RFAB_Online`, `*SkyrimTogether.esp` и `*SkyrimTogetherQuestPatches.esp` строго **ДО `RFAB.esp`** (чтобы `RFAB.esp` побеждал по 100% записей), настроит `EngineFixes.toml`, `SkyrimSoulsRE.ini`, `[RFAB] Autosave.ini`, скроет конфликтующий `BetterStealing.dll` и добавит кнопку **`RFAB Online - Play`** в MO2.
   - Установит выделенный сервер в `<Папка_RFAB>\RFAB_Online_Server` и создаст ярлык **`START_RFAB_SERVER.bat`**.

> 💡 **Хотите обновиться за пару секунд?** Распакуйте `RFAB_Online_{{VERSION_TAG}}_Quick_Update.zip` и запустите **`UPDATE_RFAB_ONLINE.bat`** — он также сам остановит старый сервер, вычистит устаревшие файлы прошлой версии и обновит клиент + UI + сервер.

## 🎮 Запуск, управление и права Хоста

1. **[Только Хост]** Запустите `<Папка_RFAB>\START_RFAB_SERVER.bat` (в окне отобразится IP-адрес для друзей, например из **Radmin VPN**).
2. **[Хост и Друзья]** В **Mod Organizer 2** выберите **`RFAB Online - Play`** → нажмите **«Запустить»**.
3. В открытом мире нажмите **`Правый CTRL`** (или **`F2`**) → **«Подключиться» (`Connect`)**:
   - **Хост:** `127.0.0.1:10578` · **Друзья:** `<IP_хоста>:10578` (группа создаётся автоматически!).

| Действие / Клавиша | Кто управляет | Описание |
|---|---|---|
| **`Правый CTRL`** / **`F2`** | **Все игроки** | Открыть оверлей кооператива (подключение, чат, группа, настройки) |
| **Кнопка «Единство в битве: ВКЛ / ВЫКЛ»** *(или `/allyprotect`)* | **Только Хост** | Включить/отключить урон и негативные эффекты по союзникам для всей группы (гости видят текущий статус Хоста) |
| **`F5`** | **Любой игрок** | Синхронно сохранить игру для **всей группы** |
| **`F9`** | **Только Хост** | Загрузить последний групповой чекпоинт для всех игроков |
| **Удерживать `E`** *(у раненого)* | **Все союзники** | Поднять упавшего на колено союзника (~4 с, с индикатором прогресса) |
| **`F10`** / **`Alt + СКМ`** *(или `/ping`)* | **Все игроки** | Поставить контекстную 3D-метку для отряда (Босс / Враг / Помощь раненому / Сундук / Рычаг / Точка сбора; `Shift+F10` — Опасность, `Ctrl+F10` — снять метки) |
| **`F11`** *(или `/hud`)* | **Все игроки** | Переключить режим тактического HUD отряда (`Полный` → `Компактный` → `Только 3D-метки` → `Скрыт`) |
