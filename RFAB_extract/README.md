# RFAB_extract — что это за данные и почему они больше не в git

Здесь лежат **выдержки из сборки RFAB и из неё же взятые игровые файлы**,
которые использовались при анализе и порте на Skyrim SE 1.5.97. Ничего из
этого не требуется для сборки клиента или сервера.

## Классификация содержимого

| Тип | Примеры | В git? | Зачем |
|---|---|---|---|
| Текстовые конфиги сборки | `MO2_profile-template_Default_*.txt`, `MO2_mods_RFAB_*.ini`, `*_Settings.json`, `Experience.ini`, `Quests.ini`, `RaceList.json` | да | воспроизводимость анализа (левел-кривые, XP-таблицы, порядок плагинов) |
| Дамп записей `RFAB.esp` | `rfab_records.tsv` (89 807 строк: `type / formid / edid / full / data / depth`) | да | оффлайн-проверка FormID и имён форм без распаковки esp |
| Извлечённые заголовки-эталоны | `SKSE_GameReferences.h`, `SKSE_GameData.cpp` | да | сверка раскладок структур с независимым источником |
| **Сторонние бинарники** | `RFAB.esp` (31 МБ), `skse64_1_5_97.dll`, `tbb.dll`, `DINPUT8.dll`, `version-1-5-97-0.bin` | **нет** (`.gitignore`) | нужны только локально для оффлайн-аудита |

## Почему бинарники убраны из репозитория

1. `RFAB.esp` — контент сборки RFAB (автор `drake1ch`), который содержит и
   ресурсы Bethesda. Публичная раздача 31-МБ плагина в git — это и вопрос
   лицензии/прав, и мусор в истории (репозиторий уже был ~83 МБ при 1.6k
   исходников).
2. SKSE / Address Library / `tbb` / `DINPUT8` — сторонние бинарники, у каждого
   свои условия распространения; проще не хранить их в git.
3. Историю от этого «худее» не станет: файлы остались в коммитах до
   `chore(repo): untrack game binaries…`. Если нужен реально маленький клон —
   отдельная операция перезаписи истории (`git filter-repo`), она **не**
   делалась и требует согласования, потому что меняет SHA всех коммитов.

## Как восстановить локально

Положите файлы в эту папку (`RFAB_extract/`) — они игнорируются git:

- `RFAB.esp`, `version-1-5-97-0.bin` — из установленной сборки RFAB
  (MO2-мод `RFAB`, папка `SKSE/Plugins`);
- `skse64_1_5_97.dll`, `tbb.dll`, `DINPUT8.dll` — из `Skyrim SE 1.5.97` +
  SKSE64 2.0.20 и поставщика dll-загрузчика.

Контрольные суммы (MD5) на момент извлечения — для проверки, что у вас те же
файлы, что были при аудите:

