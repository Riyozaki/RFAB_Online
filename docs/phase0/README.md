# Артефакты Фазы 0

* `ANALYSIS_RU.md` — основной документ анализа и план.
* `id_map_1_5_97.csv` — все 287 ссылок на Address Library ID в клиенте форка.
  Колонки: `ae_id` (ID из 1.6.x-базы), `se_1_5_97_id` (восстановленный ID для 1.5.97),
  `confidence` (`A` — точное совпадение по файлу и имени из кода до AE; `B` — по имени, требует просмотра;
  пусто — не найдено), `variable`, `type`, `kind` (`ptr` — `POINTER_SKYRIMSE`, `vdb` — `VersionDbPtr`),
  `file`, `line`, `source_2021` — откуда взят адрес 1.5.97.
* `id_map_1_5_97_todo.csv` — 139 ID (142 ссылки), которые нужно реверсить вручную.
* `id_map_summary.json` — сводные числа.

## Как получена карта

1. Из текущего дерева извлечены все `POINTER_SKYRIMSE(..., <id>)` и `VersionDbPtr<...>(<id>)`.
2. Из коммита `a53644e0^` (2021-11-09, до перехода на AE) извлечены те же объявления с сырыми адресами.
3. Адрес → RVA; RVA ищется в `version-1-5-97-0.bin` (Address Library 1.5.x из сборки RFAB).
4. Совпадение по (файл, имя) даёт уверенность **A**, только по имени — **B**.

Проверка воспроизводима; скрипт генерации будет добавлен в `tools/port1597/` в Фазе 1.
