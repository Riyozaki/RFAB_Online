# Конфигурация RFAB Online

Две независимые группы настроек:

* **серверные** — файл `Data/config/` (тот, что создаёт сервер при первом
  запуске, формат `section:key = value`), читаются при старте;
* **клиентские** — `Data/SKSE/Plugins/RFABOnline.ini` (только раздел `[Save]`).

Всё, что добавлено этим форком, **включено по умолчанию**; выключается
явным `= false` / `= 0`.

## 1. Серверные настройки

### Новые (RFAB Online)

| Ключ | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `Gameplay:bEnableHealthScaling` | bool | `true` | Максимальное HP не-игровых актёров умножается на `N+1`, где `N` — число игроков на сервере: 1 → ×1, 2 → ×3, 3 → ×4. Количество врагов не меняется. Множитель считается на сервере; клиент только применяет то, что ему сказали. Переключение на лету подхватывается на следующем тике. |
| `Gameplay:bScalePlayerSummons` | bool | `false` | Скейлить ли HP призванных игроком существ (атронах, фамильяр). По умолчанию нет: у них бывают скриптовые пороги. |
| `Gameplay:fHealthMultiplier` | float | `1.0` | **Служебное, только чтение.** Эффективный множитель, который сервис публикует клиентам внутри `ServerSettings.HealthMultiplier`. Правка в ini ни на что не влияет, пока включён `bEnableHealthScaling`; диапазон `[1, 32]`. |
| `Gameplay:bEnableRfabXpSync` | bool | `true` | Включает общий опыт: клиент сообщает «я получил X опыта», сервер рассылает это остальным. |
| `Gameplay:bXpShareWholeServer` | bool | `true` | `true` — опыт получают **все игроки сервера**; `false` — только партия (старое поведение). |
| `Gameplay:bXpBalanceNewcomers` | bool | `true` | Игрок, которого сервер ещё не видел, стартует со **средним** опытом по серверу, а не с нуля (иначе в давно идущей сессии он безнадёжно отстаёт). Среднее считается по `Data/progress/progress.jsonl`; опыт выше среднего никогда не отбирается. |
| `Gameplay:uXpReportBurst` | uint32 | `30` | Сколько отчётов об опыте клиент может отправить «залпом» (анти-спам). Один отчёт рассылается всем игрокам, поэтому поток от одного клиента усиливается в N раз. |
| `Gameplay:uXpReportsPerSecond` | uint32 | `10` | Устойчивая скорость отчётов в секунду на клиента (`0` — только залп). Нормальный трафик — примерно 1 в секунду. |
| `Gameplay:bEnableProgressionLedger` | bool | `true` | Помнить, сколько опыта сервер начислил каждому нику, в `Data/progress/progress.jsonl`. При входе игрока, у которого опыт меньше запомненного (краш, загрузка старого сейва, новый персонаж), сервер досылает разницу обычной наградой. Игрок, у которого опыт больше, не трогается. |
| `Gameplay:uXpShareDedupWindowMs` | uint32 | `5000` | Окно, в котором одинаковая сумма XP от разных игроков считается одним и тем же событием и рассылается один раз. `0` отключает эту эвристику (тогда возможны дубли при синхронном квесте). |

Маунты, игроки и мёртвые актёры не скейлятся никогда; драконы скейлятся как
обычные враги.

## 2. Клиентский `RFABOnline.ini`

Путь: `<Skyrim SE>\Data\SKSE\Plugins\RFABOnline.ini`. Шаблон с комментариями
лежит в репозитории: `GameFiles/Skyrim/SKSE/Plugins/RFABOnline.ini`.

```ini
[Save]
bStopSessionOnLoad = 1   ; загрузка сохранения в сессии закрывает соединение
bIndexSaves        = 1   ; вести индекс сейвов рядом с сохранениями
bNotifyInGame      = 1   ; сообщения в HUD
uPollIntervalMs    = 5000
```

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `bStopSessionOnLoad` | `1` | Загрузка сохранения во время игры в мультиплеере закрывает соединение. Без этого клиент остаётся в мире, которого на сервере нет (рассинхрон/вылет). |
| `bIndexSaves` | `1` | Ведёт `RFABOnline_saves_index.jsonl` в папке сохранений: имя файла, время (UTC), id сессии, адрес сервера, персонаж, размер. |
| `bNotifyInGame` | `1` | Показывать сообщения HUD о загрузке/сохранении. |
| `uPollIntervalMs` | `5000` | Период сканирования папки сохранений, мс; клампится в `[1000, 60000]`. |

Парсер терпимый: неизвестные ключи и разделы игнорируются, мусор в значении
сохраняет значение по умолчанию, ключи регистронезависимы, CRLF поддерживается.
Файла нет → все значения по умолчанию (всё включено).

## 3. Совместимость

* Опыт и HP-скейлинг работают только если на клиенте установлена сборка RFAB
  (глобал `PlayerXP` из `RFAB.esp`). Без неё функции тихо отключаются —
  в логе клиента будет `RFAB XP global ... was not found`.
* Клиент и сервер должны быть собраны **из одного коммита**: сервер сравнивает
  `BUILD_COMMIT` при аутентификации. Версия протокола (`Protocol::kVersion`)
  логируется с обеих сторон и сейчас равна **3**.

## 4. Диагностика

| Что | Где смотреть |
| --- | --- |
| Множитель HP и его пересчёт | лог сервера: `Health scaling: N player(s) -> NPC health xM` |
| Отклонённые/подавленные начисления XP | лог сервера: `XP share: rejected replayed report`, `suppressed duplicate amount` |
| Отброшенные по лимиту отчёты | лог сервера: `XP share: throttled N report(s)` (не чаще, чем раз в 100 отброшенных) |
| Отброшенные «плохие» актор-велью | лог сервера: `dropped non-finite value`, `dropped invalid max value` |
| Индекс сохранений | `<Документы>\My Games\Skyrim Special Edition\Saves\RFABOnline_saves_index.jsonl` |
| Реестр прогресса | `Data/progress/progress.jsonl` рядом с сервером: ник, опыт, уровень, последняя ячейка/позиция, время |
| Восстановление опыта | лог сервера: `Progression: restoring N XP to 'ник' (a -> b)` |
| Новый игрок и средний опыт | лог сервера: `Progression: newcomer 'ник' starts with the server average, granting N XP` |
| Сводка состояния в консоли сервера | команды `rfabstats` (множитель HP, счётчики XP, размер реестра) и `rfabflush` (сбросить реестр на диск) |
| Политика сохранений | лог клиента: `Save system: stopSessionOnLoad=... indexSaves=...` |
